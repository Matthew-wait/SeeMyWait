# v5.5 release — 2026-09-29

## Status: shipped, both platforms

- **iOS**: submitted to App Store Connect (build 1 under version 5.5), processing.
- **Android**: submitted to Google Play production track, versionCode 10.

## What changed in this release

- Ported the `nearby_clinics` PostGIS RPC + progressive (5mi-then-full-radius)
  loading from web to mobile (`src/hooks/use-clinics.ts`) — mobile no longer
  full-table-fetches `clinics`, matching the fix web needed at scale.
- Switched map tiles to free OpenStreetMap on both platforms
  (`src/components/map/MapView.tsx`, `UrlTile` + `mapType="none"`) — no
  Google/Apple Maps tile billing anywhere in the app. Trade-off: the
  "tap a Google POI icon to add it as a clinic" flow (`onPoiPress`) is gone,
  since OSM raster tiles have no clickable POI layer in `react-native-maps`.
  Parked for a future rebuild (e.g. reverse-geocode a tapped point instead).
- Regenerated the entire app icon set — every PNG under `assets/images/` had
  been bulk-overwritten with the same non-square 912x1158 asset at some
  point. New `icon.png` (1024x1024, opaque, App Store-valid),
  `android-adaptive-foreground.png`, `android-adaptive-monochrome.png`
  (also now used for the Android notification icon, which was previously
  wrongly using the full-color badge), and a restored transparent
  `logo.png` for in-app splash/loading screens.
- Linked Privacy Policy / Terms of Service from Settings (both already
  existed on web at `/privacy` and `/terms`, just weren't linked from mobile).
