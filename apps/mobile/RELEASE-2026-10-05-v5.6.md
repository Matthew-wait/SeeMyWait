# v5.6 release — 2026-10-05

## Status: iOS submitted to TestFlight; Android not yet built

- **iOS**: version 5.6, buildNumber 11. Submitted to TestFlight.
- **Android**: version 5.6, versionCode 12. Not yet built or submitted.

## What changed (parity with the web app)

- Nearby offices load in 1,000-row batches, nearest first, up to 30 batches (`nearby_clinics_batch`), same as web.
- Header count comes from the server (`nearby_clinic_count`), not the loaded length.
- List shows 50 at a time, with Load more. Radius notice under the header, same wording as web.
- Report radius and accuracy limit come from `app_settings.report_geofence_meters` (default 1000 m). Settings refresh every 30 s.
- Map draws only the offices in view (cap 1,000, same as the web viewport query), not the whole radius.

## Known gaps

- The map does not draw zoomed-out, city-wide, or whole-US views (same as web: the map shows the nearby radius).
- Not yet run on a physical device or emulator. Test before submitting.
