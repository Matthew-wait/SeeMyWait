Skipped duplicates are offices already in the database under the same name and address, so they are correct to skip. Only Florida has been measured exactly so far (5,247). Other states show “not measured” until the same check is run.

Method: the full CMS NPPES national file (~9.8M records) was pulled directly rather than the live lookup API, which caps at 1,200 results per query. Each state is geocoded in batches via the Census geocoder and imported by NPI, so re-running is always safe and never creates duplicates. Counts above are pulled live from the database at page-build time, not simulated. City lists are the top 15 by volume in each state — most states have several hundred more cities represented beyond what's shown here.
